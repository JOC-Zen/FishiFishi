# FishiFishi Frontend Prototype

Primera interfaz estatica para visualizar FishiFishi como plataforma B2B de pescados y mariscos con foco en pagos asegurados, seguimiento tipo delivery y compradores empresariales.

## Estructura

```text
frontend/
  index.html
  src/
    scripts/
      app.js
      data.js
      ui.js
    styles/
      base.css
      components.css
      layout.css
      responsive.css
```

## Principios De Arquitectura

- Separacion entre datos, renderizado e interaccion.
- CSS dividido por responsabilidad.
- Componentes visuales reutilizables mediante clases.
- Sin dependencias externas para facilitar apertura local.
- Interfaz pensada para evolucionar a React, Vue, Svelte o Next.js.

## Como Abrir

Abrir el archivo `index.html` directamente en el navegador.
