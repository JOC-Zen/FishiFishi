FishiFishi - Logotipo

Concepto Visual

Primera propuesta de logotipo para FishiFishi, pensada para una plataforma B2B mayorista de pescados y mariscos.

La direccion visual busca comunicar:

  • Confianza comercial.
  • Pago asegurado.
  • Trazabilidad de entrega.
  • Comercio internacional.
  • Producto marino sin verse infantil o demasiado retail.

Simbolo

El simbolo usa dos peces opuestos dentro de una forma solida. La composicion sugiere intercambio comercial, flujo de mercancia y validacion entre comprador y proveedor.

El trazo central funciona como una marca de avance/confianza, relacionada con el proceso clave del proyecto:

  • Pago confirmado.
  • Mercancia liberada.
  • Entrega seguida.
  • Recibido validado.

Colores

  • Verde marino: #087F7A
  • Coral operativo: #D75F45
  • Negro verdoso: #14201E
  • Gris texto secundario: #5F6F6B

Nota

Esta es una primera direccion visual. Se puede evolucionar despues hacia una version mas premium, mas asiatica/internacional, mas mexicana/exportadora o mas tecnologica segun el posicionamiento final de FishiFishi.
